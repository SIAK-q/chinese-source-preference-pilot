# 中文信源偏好 pilot：数据 / Chinese source-preference pilot: data

> **最新数据（修订版 v1）**：[`conflict_pairs.md`](conflict_pairs.md) 和 [`conflict_pairs.csv`](conflict_pairs.csv) 列出全部 604 对冲突值，中英对照。`entities_zh.jsonl`、`sources_zh.json` 和 `generation/` 是修订前的原始 pilot 记录。本页下方的已知问题针对原始 pilot 数据。
>
> **Latest data (revised v1):** [`conflict_pairs.md`](conflict_pairs.md) and [`conflict_pairs.csv`](conflict_pairs.csv) list all 604 conflict pairs, Chinese with English gloss. `entities_zh.jsonl`, `sources_zh.json` and `generation/` record the original pilot before revision. The known issues below describe the original pilot data.

硕士论文 pilot 数据，研究语言模型面对两份相互冲突的中文材料时如何权衡政府、报纸、个人和社交媒体等不同类型的信源。实体、属性值和信源名称按中文语境构造。

Pilot data for an MA thesis on how LLMs weigh different types of sources (government, newspaper, person, social media) when two Chinese-language materials conflict. The entities, attribute values and source names were built for Chinese.

这次 pilot 是可行性检查，用来测试流程能否在中文下运行，而不是判断模型偏好哪些信源。本次发布的数据供扩充前审阅。

The pilot was a feasibility check: it tested whether the procedure runs in Chinese, not which sources models prefer. This release is for reviewing the data before it is extended.

共 7 类、30 个虚构实体，151 个实体属性项，每项有 5 个值（索引 0 为原值，1–4 为备选值）。

30 fictional entities in 7 types, 151 entity–attribute items, 5 values each (index 0 = original, 1–4 = alternatives).

## 数据如何生成 / How the data was generated

数据由 Claude Opus 5根据四份指令生成（[`generation/prompts/`](generation/prompts/)）。模型将原值和备选值作为固定列表直接写入 Python 脚本。共生成 20 个虚构地名，其中 5 个用于政府信源，5 个用于报纸信源，另外 10 个用于实体名称和属性值。

The data was generated by Claude Opus 5 following four instructions ([`generation/prompts/`](generation/prompts/)). The model wrote the originals and alternatives directly into Python scripts as fixed lists. A total of 20 fictional place names were generated: 5 for government sources, 5 for newspaper sources, and the remaining 10 for entity names and attribute values.

模型看到了什么、写出了什么，以及数据如何修改：[`generation/MODEL_INPUT.md`](generation/MODEL_INPUT.md)。地名如何生成：[`generation/place_names/`](generation/place_names/)。[指令 2](generation/prompts/2_task.md) 根据最终数据整理任务要求，并未重新运行。

What the model saw, what it wrote and how the data was revised: [`generation/MODEL_INPUT.md`](generation/MODEL_INPUT.md). How the place names were made: [`generation/place_names/`](generation/place_names/). [Instruction 2](generation/prompts/2_task.md) restates the task according to the final data and was not rerun.

最终脚本生成了 [`entities_zh.jsonl`](entities_zh.jsonl) 和 [`sources_zh.json`](sources_zh.json)。要并排查看原值和备选值，可以看 [`conflict_pairs.md`](conflict_pairs.md)。

The final scripts produced [`entities_zh.jsonl`](entities_zh.jsonl) and [`sources_zh.json`](sources_zh.json). The easiest way to read originals and alternatives side by side is [`conflict_pairs.md`](conflict_pairs.md).

## 已知问题 / Known issues

1. **一个实体名称与备选值重合。** EVENT-3 通溪非物质文化遗产展演与主办方备选值“通溪市非物质文化遗产保护中心”重合（该冲突对已测试）。pilot 的名称检查只检查了一个方向。<br>**One entity name overlaps with an alternative value.** EVENT-3 通溪非物质文化遗产展演 vs organiser alternative 通溪市非物质文化遗产保护中心 (a tested pair). The name check in the pilot only tested one direction.
2. **数值备选项生成时没有设定范围。** Schuster et al.（2026）将数值变动限制在 ±20% 以内；本数据的 296 对数值中，有 177 对的差异超过 20%，例如马拉松持续时间从 1 天变为 5 天（EVENT-2）、海拔从 58 米变为 184 米（LOCATION-2）。中文数据的取值范围仍待决定。<br>**Numerical alternatives were written without a set range.** Schuster et al. (2026) vary numerical values by up to ±20%; 177 of the 296 numerical pairs here differ by more than 20%, e.g. marathon duration 1 day → 5 days (EVENT-2), elevation 58 m → 184 m (LOCATION-2). The range for the Chinese data is still to be decided.
